# 本地模式使用指南（个人电脑）

> 适用：你自己的电脑 / 宿舍台式机等，网络满足其一：**校园网直连** 或 **能访问 webvpn.zju.edu.cn**。
> 若是「云服务器 7×24」场景，请直接看 [服务器模式.md](服务器模式.md)。

---

## 1. 环境与安装

```bash
# Python 3.9+
pip install -r requirements.txt
# 可选增强(按需): 见 requirements.txt 注释
```

## 2. 网络说明（重要）

- **校园网内**：可直连 `api.cc98.org`，无需任何配置，直接跑；
- **校外（家宽等）**：
  - 先测：`curl -m 8 https://api.cc98.org/config/index` 通不通；
  - 不通 → 打开脚本配置区的 `WEBVPN_ENABLED = True` 并填 `WEBVPN_USERNAME / WEBVPN_PASSWORD`
    （浙大统一身份认证账号），执行 `pip install pycryptodome`，再跑 `python cc98_hot_monitor.py --webvpn-test` 自检；
  - 若提示 WebVPN 需要先浏览器登录/确认，先在浏览器登一次 `https://webvpn.zju.edu.cn`。
- **注**：若你在云服务器上（机房 IP 会被 webvpn 拒绝 403），WebVPN 此路不通 → 用服务器模式（zju-connect）。

## 3. 立即跑起来

```bash
python cc98_hot_monitor.py --test      # 打印当前榜单(验证抓取),不写历史
python cc98_hot_monitor.py --once      # 跑一轮并建立/更新基线
python cc98_hot_monitor.py             # 前台常驻:先跑一轮,之后每10分钟检查
```

榜单默认是「当前热门」；切榜单：

```bash
python cc98_hot_monitor.py --range week     # 本周
python cc98_hot_monitor.py --range month    # 本月
python cc98_hot_monitor.py --range history  # 历史上的今天
```

## 4. 需要登录态吗？（可选增强，匿名已够用）

榜单接口匿名即可读。若你仍想附带凭据（例如未来接口收紧）：

- **一键抓 token**：运行 `python cc98_grab_token.py`，会弹出独立 Edge/Chrome 窗口，
  在其中打开 CC98 登录页（`https://www.cc98.org/logOn`）登录一次，脚本自动把
  `access_token` 写回 `CC98_ACCESS_TOKEN` 并建立可复用的独立登录目录
  （`EDGE_USER_DATA_DIR`，登录态保留，selenium 方案可直接复用）；
- 或手动填 `CC98_USERNAME / CC98_PASSWORD`（CC98 论坛账号，OAuth 自动登录）；
- 都不填也行：接口匿名可用，token 失效会自动回退匿名。

## 5. 飞书通知 + 多维表格留档（可选）

在配置区填写：

| 配置 | 获取方式 |
|---|---|
| `FEISHU_WEBHOOK_URL` / `FEISHU_WEBHOOK_SECRET` | 飞书群 → 设置 → 群机器人 → 自定义机器人（勾选签名则填 Secret） |
| `FEISHU_BITABLE_APP_ID/SECRET` | open.feishu.cn 开发者后台 → 企业自建应用（开通 `bitable:app` 权限并发布） |
| `FEISHU_BITABLE_APP_TOKEN` 或 `FEISHU_BITABLE_WIKI_TOKEN` | 多维表格直链 `/base/{app_token}` 或知识库 wiki 节点 token（脚本自动解析） |
| `FEISHU_BITABLE_TABLE_ID` | 表 id（留空自动取该库第一张表） |

表头（文本类型，名称需与 `FEISHU_BITABLE_FIELD_MAP` 的值一致）：
`检测时间 | 榜单 | 序号 | 帖子ID | 标题 | 链接 | 作者`

自检与补写：

```bash
python cc98_hot_monitor.py --feishu-test     # 群机器人发测试消息 + 表格鉴权自检
python cc98_hot_monitor.py --feishu-seed     # 把当前 Top10 整批写入表格(初始留档)
```

之后每次发现新进榜帖子：飞书群收到合并消息，表格自动追加一行（旧行保留）。

## 6. 可视化面板

```bash
python cc98_dashboard.py            # 打开 http://127.0.0.1:8788/
python cc98_dashboard.py --port 9000 --no-browser
```

面板每 15 秒自动刷新：进程心跳、最近一轮结果、当前 Top10、事件流、日志尾部。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| `首页 HTML 中找不到任何热门话题` | 那是 SPA 正常现象；请用默认 `api` 策略，不要选 `requests` |
| 接口 401/403 | 该接口要求登录；填凭据或等自动回退匿名重试 |
| WebVPN 要求验证码/确认 | 先在浏览器手动登录一次 webvpn 再重试 `--webvpn-test` |
| 飞书写表失败 code 报错 | 核对表头列名是否与 `FEISHU_BITABLE_FIELD_MAP` 一致、应用是否发布/加入知识库 |
| 被提醒频率 | `CHECK_INTERVAL_MINUTES` 建议 ≥5，别贪快 |
