# 服务器模式使用指南（云服务器 7×24）

> 适用：阿里云/腾讯云等**云服务器（机房 IP）**。注意：机房 IP 访问
> `webvpn.zju.edu.cn`（网页 WebVPN）通常被拒（403），因此服务器模式走
> **RVPN 隧道**方案：用开源客户端 [zju-connect](https://github.com/Mythologyli/zju-connect)
> 在服务器上建立到浙大 RVPN 的隧道，监控再经该隧道访问 CC98 —— 实测可行。

## 架构

```
        ┌──────────────────────────── 阿里云/腾讯云(机房IP) ────────────────────────────┐
 定时    │  cc98-monitor.service ──(CC98_PROXY=socks5h://127.0.0.1:1080)──┐             │
 触发 ──▶│  (cc98_hot_monitor.py)                                        ▼             │
        │  zju-connect.service ──► SOCKS5 :1080 ──► RVPN 隧道 ──► 校园网 ──► api.cc98.org │
        │  cc98-dashboard.service ─► 127.0.0.1:8788(面板)                              │
        └──────────────────────────────────────────────────────────────────────────────┘
           飞书群/多维表格 ←────────────── 出站 HTTPS(无需进校网)
```

## 1. 前置

- 一台 Linux 云服务器（推荐 Ubuntu 22.04），root 或 sudo；
- Python 3.9+；能出公网（访问 GitHub、飞书）；
- 浙大统一身份认证账号（学号/工号 + 密码）。

## 2. 安装与部署

```bash
# 上传文件(建议用 deploy/server_setup.sh 或手动 scp):
#   cc98_hot_monitor.py  cc98_dashboard.py
sudo mkdir -p /opt/cc98 && cd /opt/cc98
python3 -m venv venv
./venv/bin/pip install -U pip
./venv/bin/pip install requests beautifulsoup4 schedule pysocks   # 隧道需要 pysocks
```

## 3. 建立 RVPN 隧道（zju-connect）

```bash
# 下载 zju-connect linux/amd64(去 releases 页找),放到 /opt/
cd /opt && unzip zju-connect-linux-amd64.zip && chmod +x zju-connect

# 前台验证(会看到 SOCKS5 server listening on :1080):
export ZJU_CONNECT_PASSWORD='你的统一认证密码'
./zju-connect -protocol easyconnect -server rvpn.zju.edu.cn -port 443 -username '你的学号'
```

> 首次登录若提示短信/图形验证，先在浏览器登录一次 `rvpn.zju.edu.cn` 完成新设备授权再重试。
> 若你的校园网用 aTrust 新版网关，改用 `-protocol atrust`（详见 zju-connect 文档）。

隧道测试（另开终端）：

```bash
curl -sS -m 12 -x socks5h://127.0.0.1:1080 -o /dev/null -w '%{http_code}\n' \
  https://api.cc98.org/config/index        # 期望 200
```

## 4. 让监控走隧道

在 `/opt/cc98/cc98_hot_monitor.py` 配置区：

```python
CC98_PROXY = "socks5h://127.0.0.1:1080"   # 让 DNS 也走隧道(解析到校网内 10.x)
```

```bash
cd /opt/cc98 && ./venv/bin/python -u cc98_hot_monitor.py --once
# 期望: 本次抓取成功…共 10 条
```

## 5. systemd 常驻（一条命令初始化）

```bash
cd /opt/cc98
sudo bash deploy/server_setup.sh     # 交互式输入学号/密码,自动创建三个服务并启用
```

或手动：把 `deploy/` 下的三个 `.service` 复制到 `/etc/systemd/system/`，把学号填进
`zju-connect.service`，密码写入 `/etc/zju-connect.env` 并 `chmod 600`：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now zju-connect cc98-monitor cc98-dashboard
```

验证：

```bash
systemctl is-active zju-connect cc98-monitor cc98-dashboard
journalctl -u zju-connect -n 8 --no-pager          # 应见 VPN client started / SOCKS5 listening
tail -n 5 /opt/cc98/cc98_hot_monitor.log           # 应见 抓取成功
```

服务器重启后 systemd 会自动按序拉起隧道 → 监控 → 面板，无需人工干预。

## 6. 一键体检

```bash
# 安装目录含 deploy/ 子目录,直接:
bash /opt/cc98/deploy/health_check.sh        # 三服务/端口/隧道/监控新鲜度/飞书/磁盘
bash /opt/cc98/deploy/health_check.sh -f     # 附赠一次飞书连接测试
# 退出码 = 严重故障数,可接告警
```

## 7. 从你电脑看面板

```bash
# 本机 PowerShell(保持窗口):
ssh root@服务器IP -N -L 8788:127.0.0.1:8788
# 浏览器打开 http://127.0.0.1:8788/
```

面板默认只监听 127.0.0.1，勿直接对公网开放。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| `webvpn` 登录页 403 | 机房 IP 被网页 WebVPN 拒 —— 用 zju-connect 隧道方案，勿再试 webvpn |
| zju-connect 报 `https://:443` 空服务器 | 忘了 `-server rvpn.zju.edu.cn` |
| 监控偶发首轮失败 | 隧道刚起/网络抖动；内置重试会自动成功（也可调大 `HTTP_RETRIES`） |
| 隧道掉线 | `Restart=always` 会自动重连；频繁掉线先手动浏览器登一次 rvpn 完成终端授权 |
| 磁盘/日志膨胀 | 日志自轮转；必要时加 logrotate |

## 9. 安全提醒

- 密码放 `/etc/zju-connect.env`（`chmod 600`），勿写进代码/命令行历史；
- 飞书 App Secret 等请用环境变量或本地私有配置管理。
